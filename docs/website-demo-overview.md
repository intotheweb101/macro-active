# MacroActive Website Demo Overview

This website is a small Laravel demo app built to show how a team can combine product thinking, engineering workflow, and AI-assisted delivery in a practical way.

## What it is demoing

- A clean local development setup using Laravel and DDEV
- Product-facing UI pages that reflect creator onboarding, health, and operations workflows
- A real AI integration with the `Creator Launch Assistant`, using z.ai to turn a creator brief into a launch plan
- Review-friendly branch and pull request workflows for feature work, pipeline work, and AI changes
- CI/CD and release process examples that support safe delivery rather than replacing engineering judgement

## Key pages

- `Overview` — frames the repo as a delivery and collaboration demo
- `Creator ops` — shows onboarding status, health signals, and timeline-style product UI
- `Launch assistant` — shows an on-brand AI feature with validation, config, and graceful error handling
- `Engineering` — shows how branches, code review, and release automation fit together

## What to talk through

This demo is useful for explaining how developers stay in control while AI helps with speed, structure, and first-pass generation. It also gives a clear way to talk about branch strategy, review quality, release confidence, and how product requirements become working software.

## Suggested demo story

Start with the overview page, move into creator operations, show the launch assistant as the AI example, and finish on the engineering page to connect everything back to team workflow and delivery.
